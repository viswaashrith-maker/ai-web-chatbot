# 🤖 AI Web Chatbot

A simple and interactive web-based chatbot built using Python and Flask.  
This project demonstrates how backend logic can be combined with a clean user interface to create a real-time conversational application.

---

## ✨ Features

- 💬 Chatbot with predefined responses  
- 🌐 Web interface using Flask  
- 🧠 Structured response handling using functions  
- 📜 Chat history display  
- 🌙 Dark mode UI  
- 💭 Chat bubble design (like real messaging apps)  
- 🔄 Auto-scroll to latest message  
- 🧹 Clear chat button  

---

## 🛠️ Technologies Used

- Python 🐍  
- Flask 🌐  
- HTML  
- CSS
